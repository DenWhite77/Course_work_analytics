# Курсовая работа: Анализ банковских транзакций

**Комплексная аналитическая система для анализа банковских транзакций 
из Excel с генерацией JSON для веб-интерфейсов. Реализованы: поиск по описанию 
и телефонам, инвесткопилка, API для курсов валют и акций.**

### 1.Возможности

#### 📊 Анализ транзакций
- **Чтение Excel-выгрузок** — загрузка транзакций из файлов `.xlsx`/`.xls`
- **Фильтрация по периоду** — выборка данных за неделю, месяц, год или весь период
- **Расходы по категориям** — группировка трат с выделением топ-7 категорий
- **Поступления по категориям** — анализ доходов по источникам

#### 🔍 Поиск и фильтрация
- **Поиск по описанию/категории** — быстрый поиск транзакций по тексту
- **Поиск телефонных номеров** — автоматическое обнаружение номеров в описании платежа

#### 💰 Инвестиционные инструменты
- **Инвесткопилка** — расчёт суммы, которую можно откладывать (округление трат до заданного шага)
- **Курсы валют** — получение актуальных курсов через публичное API
- **Цены акций** — интеграция с Alpha Vantage API для получения котировок

#### 🌐 Веб-интеграция
- **Главная страница** — JSON-дашборд с картами, топ-транзакциями, курсами и приветствием
- **Страница событий** — детальная аналитика расходов и доходов по категориям
- **Готовая JSON-структура** — данные для фронтенд-приложений (React, Vue, Svelte)

#### 🧪 Качество кода
- **Модульные тесты** — покрытие ключевых функций (pytest)
- **Логирование** — отладка и мониторинг работы
- **Типизация** — аннотации типов для всех функций

### 4. Установка

**Клонирование репозитория**
git clone https://github.com/DenWhite77/Course_work_analytics.git
cd course_work_analytics

**Создание виртуального окружения**
python -m venv .venv
source .venv/bin/activate      # Linux/Mac
.venv\Scripts\activate         # Windows

**Установка зависимостей**
pip install -r requirements.txt

**Настройка переменных окружения**
Сщздайте файл .env в корне проекта:
ALPHA_VANTAGE_KEY=ваш_ключ_alpha_vantage
(Получить ключ можно бесплатно на Alpha Vantage)

**Подготовка данных**
Поместите файл с транзакциями в data/operations.xlsx в формате:
* Дата операции — дд.мм.гггг
* Категория — текст
* Сумма платежа — число (отрицательное = расход)
* Описание — текст
* Номер карты — число (опционально)

### 5.Использование(CLI в клммандной строке):
* Анализ трат по категории за 3 месяца
python src/reports.py

* Поиск транзакций
python -c "from src.services import search_main; print(search_main('Перевод'))"

* Генерация JSON для главной страницы
python -c "from src.views import main_page; print(main_page('2021-12-31 23:59:59'))"

### 6.Основные функции:

* utils.py - утилиты:
read_excel_operations(file)	- Чтение Excel → список транзакций;
filter_by_date_range(data, date, period) - Фильтрация (W/M/Y/ALL);
get_currency_rates(currencies) - Курсы валют через API;
get_stock_prices(stocks) - Цены акций через Alpha Vantage.

* services.py - бизнес-логика:
search_transactions(data, query) - Поиск по описанию/категории;
search_phone_numbers(data) - Поиск транзакций с телефонами;
investment_bank(data, limit) - Инвесткопилка (округление до limit).

* views.py - генерация JSON:
main_page(date) - Главная страница: карты, топ-5, курсы;ъ
events_page(date, period) - Страница событий: расходы/доходы.

* reports.py - анализ трат:
spending_by_category(data, category, date) - траты по категории за 3 месяца.

#### Входные и выходные данные(пример):

**Входные данные (Excel)**
Файл `operations.xlsx` должен содержать колонки:
- `Дата операции` — формат `дд.мм.гггг`
- `Категория` — текст (например, "Супермаркеты")
- `Сумма платежа` — число (отрицательное для расходов)
- `Описание` — текст (назначение платежа)
- `Телефон` — номер телефона получателя (опционально)

Пример:
| Дата операции | Категория     | Сумма платежа |
|---------------|---------------|---------------|
| 01.12.2021    | Супермаркеты  | -1500.50      |
| 02.12.2021    | Транспорт     | -200.00       |

**Выходные данные (JSON)**
Результат сохраняется в `data/result.json` и содержит структурированные данные для веб-страниц:

{
  "expenses": {
    "Супермаркеты": 15000.50,
    "Кафе": 5000.00,
    "Транспорт": 3000.00
  },
  "income": {
    "Зарплата": 50000.00,
    "Кэшбэк": 500.00
  },
  "top5": [
    {"category": "Супермаркеты", "amount": 15000.50},
    {"category": "Кафе", "amount": 5000.00}
  ],
  "cashback": 500.00,
  "investment_savings": 2500.00
}
