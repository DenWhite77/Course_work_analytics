# Курсовая работа: Анализ банковских транзакций

Приложение для анализа выгрузки транзакций из Excel. 
Генерирует JSON для веб-страниц (расходы, доходы, топ-5, кешбэк). 
Реализованы: поиск по описанию и телефонам, инвесткопилка, API для курсов валют и акций.

**Стек:** `pandas`, `requests`, `dotenv`, `pytest`, `logging`, `re`.
